# Carson × Cognition — SDR Playbook

A single-page interactive outbound sales playbook, built as a personal portfolio piece for an SDR interview with Cognition.

**Personal project — not affiliated with or endorsed by Cognition.** Customer results cited from Cognition's public customers page.

## Stack

- Vite + React 19 + TypeScript
- Tailwind CSS v4
- Framer Motion (scroll reveals, count-ups, scrollspy)
- Lucide icons

## Develop

```bash
npm install
npm run dev
```

## Deploy (GitHub Pages)

```bash
npm run build
npm run deploy   # pushes dist/ to the gh-pages branch
```

Then in the repo: **Settings → Pages → Source: "Deploy from a branch" → `gh-pages` / (root)**.
